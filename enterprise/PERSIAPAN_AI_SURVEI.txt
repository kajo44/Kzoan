APRJ NEXT — PERSIAPAN AI SURVEI JALAN
======================================

TUJUAN
------
Panduan ini menyiapkan dependensi, bobot awal ResNet-18, dataset berlabel, training,
dan pengujian inferensi. Bobot ImageNet saja tidak menghasilkan model kondisi jalan
APRJ. Model survei membutuhkan checkpoint yang dilatih dari label relevan.

A. PERSIAPAN
------------
1. Gunakan Windows 10/11 x64 dan Python 3.11 x64.
2. Pastikan folder enterprise memiliki aprj_main.py, requirements.txt,
   prepare_pretrained_model.py, dan prepare_ai_training.bat.
3. Jalankan prepare_ai_training.bat.
4. Tunggu instalasi PyTorch dan penyiapan bobot dasar selesai; koneksi internet
   diperlukan jika bobot belum tersedia secara lokal.
5. Buka aplikasi dan masuk ke tab Rekayasa AI.

Script memakai virtual environment enterprise\.venv. Script tidak membuat
checkpoint survei palsu dan tidak seharusnya menghapus model/dataset yang ada.

B. MENYIAPKAN DATASET
---------------------
1. Pada Survei Jalan, pilih foto sumber yang memang boleh digunakan.
2. Isi kondisi perkerasan, bahu, drainase, dan lebar sesuai hasil yang diverifikasi.
3. Simpan penilaian dan ekspor ke Excel.
4. Pada Rekayasa AI, impor file Excel sesuai kontrol yang tersedia, tinjau data,
   lalu konfirmasi impor. Pastikan path sumber foto masih valid.
5. Jalankan validasi dataset; perbaiki label kosong, file hilang, dan nilai tidak valid.
6. Jangan memindahkan foto sumber selama training. Bila dipindah, validasi/relokasi
   path sebelum training ulang.

Syarat teknis minimal yang diterapkan training adalah dua foto berlabel yang tersedia
dan setidaknya satu tugas klasifikasi dengan dua kelas berbeda atau target regresi
lebar yang memenuhi syarat. Ini hanya syarat untuk mulai, bukan jaminan akurasi.
Gunakan data yang representatif dan data validasi/uji yang terpisah.

C. TRAINING DAN INFERENSI
-------------------------
1. Pilih "Latih ulang dari awal" untuk membuat checkpoint baru.
2. Pilih "Lanjutkan dari model aktif" hanya jika checkpoint yang sesuai tersedia.
3. Atur epoch, batch, dan perangkat sesuai kemampuan komputer.
4. Mulai training dan tunggu status selesai/gagal. Periksa log jika gagal.
5. Pastikan checkpoint APRJ tersimpan di survey_ai\models\survey_multi_task_model.pth.
6. Gunakan "Periksa Kesiapan Model" lalu uji foto yang tidak dipakai sebagai data latih.
7. Bandingkan hasil dengan penilaian manusia; jangan menganggap prediksi benar otomatis.

D. MODE AI DAN POP-UP
---------------------
Pada toolbar Survei Jalan:
- MODE AI: ON mengaktifkan prediksi otomatis saat foto dimuat/berpindah.
- MODE AI: OFF menghentikan prediksi otomatis.
- POP-UP AI: ON (default) menampilkan konfirmasi sebelum saran AI diterapkan.
- POP-UP AI: OFF menerapkan saran ke form tanpa dialog konfirmasi penerapan.
  Ini tidak mematikan popup error/diagnostik dan tidak menyimpan penilaian final
  secara otomatis. Tinjau form dan simpan penilaian seperti biasa.

Pengaturan POP-UP AI disimpan pada config\survey_session.json. Sesi lama yang
belum memiliki nilai ini menggunakan default ON agar perilaku sebelumnya dipertahankan.
Jika checkpoint tidak tersedia atau inferensi gagal, aplikasi tetap dapat menampilkan
pesan error. Toggle ini hanya mengendalikan dialog konfirmasi hasil prediksi.

E. FILE MODEL
-------------
enterprise\pretrained\resnet18-f37072fd.pth
  Bobot umum ImageNet sebagai titik awal training.

survey_ai\models\survey_multi_task_model.pth
  Checkpoint APRJ hasil training; digunakan oleh inferensi.

Jangan mengganti nama file pretrained menjadi checkpoint APRJ.

F. PEMECAHAN MASALAH
--------------------
- Bobot pretrained hilang: jalankan prepare_pretrained_model.py.
- Training gagal: baca pesan lengkap dan logs; periksa dataset, path, ruang disk,
  dan kompatibilitas PyTorch/torchvision.
- Foto sumber hilang: pulihkan lokasi atau perbaiki path dataset lalu validasi ulang.
- Checkpoint gagal dimuat: simpan salinan dan periksa log sebelum mengganti file.
- CPU lambat: proses bisa lebih lama daripada GPU yang didukung.

BATASAN
-------
Prediksi AI adalah saran, bukan keputusan resmi. Estimasi lebar dari foto memerlukan
kalibrasi dan validasi lapangan. Kualitas model bergantung pada dataset, label,
representativitas, dan evaluasi; jumlah foto minimum teknis tidak menjamin akurasi.
