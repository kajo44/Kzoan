BATAS KLAIM
-----------
Bedakan fitur yang telah diubah di source, tes otomatis yang benar-benar dijalankan,
dan pengujian yang masih memerlukan Windows/perangkat pengguna. Jangan menyatakan
build atau validasi model selesai tanpa bukti eksekusi. Prediksi AI dan Map Matching
adalah bantuan analitis; verifikasi petugas tetap diperlukan.

FITUR ANTARMUKA TERKINI
-----------------------
- MODE AI ON/OFF mengendalikan apakah prediksi foto aktif dijalankan otomatis.
- POP-UP AI ON meminta konfirmasi sebelum saran prediksi diterapkan ke form.
- POP-UP AI OFF menerapkan saran ke form tanpa dialog konfirmasi. Hasil tetap
  perlu ditinjau dan disimpan manual; popup error/diagnostik tetap aktif.
- Preferensi POP-UP AI disimpan di config/survey_session.json dan default ON untuk
  sesi lama yang belum memiliki nilai pengaturan tersebut.
- Tombol CLEAN berada di tab Rekayasa AI dan ditujukan hanya untuk cache/berkas
  sementara yang dikenal, bukan database, foto sumber, dataset, atau checkpoint.
- Ekspor hasil proses Excel menggabungkan hasil survei, geospasial, dan diagnostik
  Map Matching yang tersedia pada sesi/proses terakhir.

ALUR PEMELIHARAAN
-----------------
1. Pastikan branch crg_aprj aktif dan tinjau perubahan sebelum commit.
2. Perbarui tes regresi untuk perubahan perilaku.
3. Dari folder enterprise, jalankan:
   python -m compileall -q .
   python -m unittest discover -s tests -v
4. Jalankan build_portable.bat pada Windows dengan Python/dependensi yang didukung.
5. Uji startup, pemuatan foto, simpan/pulihkan sesi, mode AI, kedua mode POP-UP AI,
   ekspor Excel/CSV, training/inferensi, Map Matching, metadata, dan Integrasi Online.
6. Uji paket ONEDIR pada Windows bersih. Bagikan seluruh folder dist\APRJ_Next.

DATA DAN KEAMANAN
-----------------
- Dataset merujuk path foto sumber; jangan menyalin/memindahkan foto diam-diam.
- Jika foto dipindah, jalankan validasi path dataset sebelum training.
- Jangan menghapus manifest, database, model, hasil training, atau file pengguna
  sebagai bagian dari CLEAN atau refactor umum.
- Jangan menganggap bobot ImageNet sebagai model kondisi jalan yang siap pakai.
- Validasi model dengan data terpisah dan pemeriksaan lapangan sebelum operasional.
