PRINSIP KERJA
-------------
1. Fokus pada APRJ Next di branch crg_aprj. Jangan mencampur proyek GeoSurvey/GeoSurveyJalan_Next.
2. Jangan menghapus dataset, manifest, database, checkpoint model, atau file sumber pengguna saat refactor.
3. Jangan mengklaim fitur atau pengujian berhasil sebelum benar-benar dijalankan.
4. Pisahkan fakta, asumsi, dan estimasi pada dokumentasi serta laporan pengujian.
5. Prediksi AI dan hasil map matching adalah bantuan analitis; verifikasi petugas tetap diperlukan.

ALUR PENGEMBANGAN
-----------------
1. Pastikan branch crg_aprj aktif dan buat backup/commit sebelum perubahan.
2. Baca modul terkait dan tes yang sudah ada sebelum mengubah API atau format data.
3. Perbarui tes regresi untuk perilaku baru dan kasus error/fallback.
4. Jalankan:
   python -m compileall -q .
   python -m unittest discover -s tests -v
5. Untuk build Windows, jalankan build_portable.bat dari folder enterprise.
6. Build memerlukan internet pada persiapan awal bobot pretrained. Setelah dibundel,
   aplikasi portable tidak perlu internet untuk memuat bobot model tersebut.
7. Uji EXE pada komputer build dan komputer Windows bersih; salin seluruh folder
   dist\APRJ_Next, bukan hanya APRJ_Next.exe.

MODEL DAN DATASET
-----------------
- Foto dataset dirujuk lewat path sumber; impor tidak boleh diam-diam memindah foto.
- Jika foto sumber dipindah, validasi/relokasi dataset perlu dijalankan.
- Latih ulang dari awal menggunakan backbone ResNet-18 ImageNet dan kepala APRJ baru.
- Lanjutkan dari model aktif menggunakan arsitektur yang tersimpan di checkpoint.
- Checkpoint lama tanpa metadata architecture dianggap legacy_cnn agar tetap terbaca.
- Jangan menyebut ImageNet pretrained sebagai model kondisi jalan yang sudah matang.
- Model baru harus dilatih dengan label survei yang sesuai, diuji pada data validasi,
  dan hasilnya diverifikasi secara lapangan sebelum penggunaan operasional.
